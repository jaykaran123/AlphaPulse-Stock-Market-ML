Core Mathematical Formulations & Loss Specifications
1. Gradient Tree Boosting Loss Function (Huber / MSE)
$$F_m(x) = F_{m-1}(x) + \gamma_m h_m(x), \quad r_{im} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}$$

Sequentially fits decision trees to the negative pseudo-residuals, learning non-linear relationships without feature co-linearity assumptions.

2. Quantile Pinball Loss Function (90% Envelope)
$$\mathcal{L}_\tau(y, \hat{y}) = \max(\tau(y - \hat{y}), (\tau - 1)(y - \hat{y})), \quad \tau \in \{0.05, 0.95\}$$

Delivers asymmetric penalization, yielding distribution-free 5th and 95th percentile risk bounds for 1-day Value-at-Risk modeling.

3. Random Forest Bagging Variance Reduction
$$\text{Var}(\bar{X}) = \rho \sigma^2 + \frac{1-\rho}{B}\sigma^2$$

Reduces variance on high-volatility trading days through bootstrap aggregating of 100 decorrelated decision trees.

4. SVR Non-Linear Radial Basis Function (RBF)
$$L_\varepsilon(y, f(x)) = \max(0, |y - f(x)| - \varepsilon), \quad K(x, x') = \exp(-\gamma ||x - x'||^2)$$

Finds a flat maximum-margin hyperplane in an infinite-dimensional Hilbert space, ignoring small fluctuations inside ε.
